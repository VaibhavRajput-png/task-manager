
# Task Manager

A simple full-stack task management application built using HTML, CSS, JavaScript, Node.js, Express.js and SQLite.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Store tasks in a SQLite database

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: SQLite
- Data Exchange: JSON
- Package Manager: npm

## Software Development Life Cycle (SDLC)

### 1. Requirement Analysis
Develop an application that allows users to manage their daily tasks.

### 2. Planning
Select the technologies, identify the required features and organize the project structure.

### 3. System Design
Design the frontend, backend REST API and database schema.

### 4. Implementation
Develop the frontend, backend and database functionality.

### 5. Testing
Test task creation, retrieval, completion and deletion.

### 6. Deployment
Prepare the application to run on a server.

### 7. Maintenance
Fix bugs, improve performance and add new features.

## Installation

1. Install Node.js.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run `npm install`.
5. Create a `.env` file containing `PORT=5000`.
6. Run `npm run dev`.
7. Open `frontend/index.html` using VS Code Live Server.
